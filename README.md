# SkinAugment AI

Consumer Skincare Photo Augmenter.

## Features
- Upload skincare photographs
- Generate image variations
- Preview and download augmented images
- Optional EfficientNet-B0 classification

## Run
pip install -r requirements.txt
streamlit run app.py

## Model checkpoint
Place the trained checkpoint at:
models/efficientnet_b0_phase4_best.pth

This application is an image augmentation research tool, not a medical diagnostic system.
